## The version system (the user's #1 requirement)
* v1 = the original game, frozen runnable copy in `versions/v1/`. Every later update is a **pack**: `js/pack_vN.js`, content entries tagged `pack: 'vN'`, switchable on the in-game **VERSIONS** screen (title, top right), saved in `meta.packs` (false = off, default ON), URL `?packs=v1|all|v2,v4`, env `ED_PACKS=none|all|v2,v4` for all test tools.
* Rules: packs are independent; never consume RNG / change behaviour for pack content when the pack is off (v1 parity: `node test/parity.js`); filter pools with `ED.packs.ok(def)` / `ED.packs.values(table)` / `ED.packs.on('vN')`.
* After finishing an update: `node test/matrix.js` (parity + v1 + each pack alone + all) must be green, then `./snapshot.sh vN` (never overwrite v1).
* Extension points (all in `js/packs.js`): `ED.hook(name, pack, fn)` names tick/runStart/floorStart/roomEnter/roomClear/kill/spawn/draw/under/intro/hud/guardBreak/runEnd/miniDefeated/selectUI/titleUI/endUI; registries `ED.weaponImpl, activeImpl, bossDraw, partDraw, partPos, modalImpl, sceneImpl`; helpers `ED.items.addRelic`, `ED.packs.define/track`.

## Gotchas learned
* `hitstop` freezes the world: after `destroyPart`/crit etc. step ≥ 40 frames in tests. A modal freezes the world too. `rt.worldOn` gates v3 hazards to combat rooms only.
* Tests must be deterministic (harness seeds `Math.random`), but different pack configs consume it differently — write assertions that don't depend on room layout luck (place player via `g.freeSpot`, clear `rt.enc`, etc.).
* v1 bugs fixed (parity still exact): relicEvent arg order (Blood Pact), stun on invulnerable foes, fused-boss `anchors` on part-less bosses, **foes spawned inside a brazier** (a stationary Spiral Idol on a puzzle brazier could not be hit by anything that shoots — shots stop at the unbreakable prop — so a ranged-only build was locked in the room; `G.clearBraziers` in entities.js lifts them off it, regression test P0h).
* `ED.input.sim` is shared state: a Bot that ends a test mid-stride leaves its last held keys behind and the next test's player walks off (intermittent v7 "freeing a slot lets you collect it" failure). `arena()` in pack-tests.js now resets it; do the same in any new helper that builds a game.
* Don't use enemies that spray bullets (spinners) as boss adds — they hit the 280 bullet cap.
